# MSU2 USB 副屏性能监控 Demo

适用于 MSU2 / MSU2_MINI 系列可编程 USB 副屏（1.54 寸 160×80，CH32X033 主控 + P25D80 闪存）的**纯性能监控程序**，不投屏、资源占用低。

屏幕硬件为串口指令控制（非扩展显示器），本程序通过串口与其通信。

## 功能

- 四宫格监控界面：**CPU 占用率 / 内存占用率 / 磁盘占用率 / 显卡或电池**（沿用原厂背景位图布局）
- `--nv`：NVIDIA 全显卡模式 —— GPU 核心温度 / 显存占用% / 功率% / 利用率
- `--flip`：画面 180° 翻转
- 每 0.5 秒刷新，串口出错自动检测退出

## 安装与运行

```bash
pip install pyserial psutil
# NVIDIA 模式无需额外依赖（使用驱动自带的 nvidia-smi）

python MSU2_监控demo.py              # 普通监控，右下角显卡利用率
python MSU2_监控demo.py --flip       # 180° 翻转
python MSU2_监控demo.py --item battery   # 右下角改为电池电量
python MSU2_监控demo.py --nv         # NVIDIA 四宫格（默认同时翻转）
```

运行前请关闭厂商"USB 屏幕助手"和原版投屏程序（串口独占）。若找不到设备，临时关闭电脑蓝牙后重新插拔屏幕。

## 通信协议（逆向笔记）

波特率 19200，6 字节定长帧，小端：

| 帧 | 含义 |
|---|---|
| `[2, 0, x_hi, x_lo, y_hi, y_lo]` | 设置光标坐标 |
| `[2, 1, w_hi, w_lo, h_hi, h_lo]` | 设置显示区域尺寸 |
| `[2, 2, fc_hi, fc_lo, bc_hi, bc_lo]` | 设置前景/背景色（RGB565） |
| `[2, 3, 1, page_hi, page_lo, 0]` | 显示闪存第 page 页的单色位图 |

- 位图指令发出后主控回显帧头 `[2,3]` 确认
- 设备握手：屏幕周期性广播 `"MSN"+两位数字`，PC 回复 `\x00MSNCN`，屏幕回显确认
- 显示方向：`[2, 3, 10, state, 0, 0]`，0=正常，1=180° 翻转
- 数字位图在闪存第 4026~4037 页（0~9、"1"、空白），背景在 3939~4038 页
- 屏幕自带 1MB 闪存（256B × 4096 页），位图由主控本地读取渲染，因此串口流量极小

协议细节逆向还原过程见 `MSU2_MINI_DemoV1.6_程序分析报告.md`（本仓库未包含该文件，可联系作者索取）。
